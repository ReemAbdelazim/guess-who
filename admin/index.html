Sign in with your GitHub token

Saving commits your changes to the guess-who repository. The game updates about a minute after each save.

How do I get a token?
  1. Open github.com/settings/personal-access-tokens/new.
  2. Under Repository access, choose Only select repositories and pick guess-who.
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Generate the token and paste it above. Keep it private: anyone with it can edit the game.
